# 데일리 루틴 (Daily Routine)

아이폰 사파리에서 **홈 화면에 추가**해 앱처럼 쓰는 모바일 데일리 루틴 PWA.
서버 없이 브라우저 `localStorage`에 모든 기록을 저장합니다.

- 앱 주소: <https://ccbskorea.github.io/daily-routine/>
- 홈 화면 추가: Safari로 열기 → 공유 → **홈 화면에 추가**

## 화면 구성

| 탭 | 내용 |
| --- | --- |
| **오늘** | 오늘의 달성률·연속 달성일, 시간대별(모닝·데이·나이트) 루틴 체크, 수면·러닝·독서·필사 바로가기 |
| **러닝·수면** | 취침/기상 시간 입력 → 총 수면 시간 자동 계산, 최근 7일 수면 막대, 러닝 거리·페이스 기록, 페이스 추이 차트 |
| **기록** | 독서 기록(책·분량·메모), 하루 한 문장 필사와 모음 |
| **달력·렌즈** | 월간 달성 달력(날짜 탭 → 그날 기록 조회/수정), 렌즈 개봉일·경과일(D+N)·교체 예정 알림 |

## 기본 루틴

- ☀️ 모닝: 💧 아침 공복 미지근한 물 한 잔 / 🧘‍♀️ 스트레칭 15분 / 💊 영양제 챙겨 먹기
- 🌤 데이: 🏃‍♀️ 러닝 뛰기
- 🌙 나이트: ✨ 화이트랩스(치아미백) 이용 체크

루틴은 화면 우측 상단 버튼에서 추가·수정·삭제·순서 변경이 가능합니다.

## 개발 메모

- `index.html` · `styles.css` · `app.js` · `manifest.json` · `sw.js` · `icons/`
- 저장 키: `dailyRoutine.v2` (이전 `dailyRoutine.v1` 데이터는 자동 이전)
- 오프라인 동작을 위해 서비스 워커가 앱 껍데기를 캐시합니다.
- 러닝을 저장하면 이름에 '러닝'이 들어간 루틴이 오늘 자동 체크됩니다.
